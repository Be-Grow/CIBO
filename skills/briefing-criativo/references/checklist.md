# Checklist de decisões do briefing

Cada linha: o que decidir, de onde costuma vir a resposta e opções típicas para a pergunta.
Marque cada uma como **definido (fonte)** ou **em aberto** antes de perguntar.

## A. Editorial (primeira rodada)

| Decisão | Fonte habitual | Opções típicas |
|---|---|---|
| Perfil que posta / dono do corte | pedido, registro de clientes | cliente X; convidado; collab entre perfis |
| Objetivo do corte | pedido, bíblia | autoridade; venda/CTA; alcance/viral; bastidor; educativo |
| Plataforma e formato | pedido | Reels/TikTok 9:16; Shorts; feed 4:5; YouTube 16:9 |
| Quantidade e duração | pedido | n cortes; 30–45 s; 45–60 s; até 90 s |
| Tom | bíblia, referências | provocativo; inspirador; técnico; leve/humor |
| Tipo de gancho | bíblia | pergunta; afirmação polêmica; número/dado; história |
| Ritmo dos cortes | bíblia | agressivo (pausas de 0,25–1 s viram 0,1 s); equilibrado (0,3 s); sentimental (0,5 s); documental (mantém) |
| Seleção dos momentos | regra transversal | editor já tem os tempos; IA escolhe e mostra o mapa |
| Assuntos proibidos / obrigatórios | pedido, cliente | marca citada, concorrente, dado sensível |
| Quem aparece | gravação | só o convidado; inclui entrevistador; plateia |

## B. Visual (segunda rodada)

| Decisão | Fonte habitual | Opções típicas |
|---|---|---|
| Enquadramento | skill do cliente | close fixo por plano; segue o rosto; plano aberto quando houver slide |
| Marca de terceiros no bruto | gravação | reenquadrar para tirar; manter como crédito |
| Legenda: estilo | skill do cliente | estática; palavra a palavra; caixa alta; cor de destaque |
| Legenda: posição e tamanho | regra transversal | abaixo do queixo; terço inferior |
| Palavras de destaque | job | IA escolhe; lista do editor |
| Título de gancho na tela | lettering-motion | sim, nos 3 primeiros s; não |
| Cartão "Seguir"/@ | lettering-motion | sim, com a foto atual do perfil (pedir o arquivo); não |
| Lower third / nome | lettering-motion | sim; não |
| B-roll / referência em tela | semantic-broll-validator | não; split; tela cheia; card |
| Zoom e movimento | regra transversal | sem zoom; zoom suave de ênfase |
| Transições | skill do cliente | film burn da marca; corte seco |
| Capa: frame | regra transversal | close de rosto olhando para a câmera; sorriso; gesto |
| Capa: manchete e layout | skill do cliente | texto da manchete; posição; cor |
| Cor / grade | skill do cliente | natural; mais contraste; look da marca |
| Logo do cliente | brand profile | canto; só na capa; sem logo |

## C. Som (segunda rodada)

| Decisão | Fonte habitual | Opções típicas |
|---|---|---|
| Trilha: clima | talking-head-music | motivacional; corporativo leve; tensão; sem trilha (raro) |
| Trilha: energia sob a voz | regra transversal | presente desde o 1º s, ~16–20 dB abaixo |
| SFX de ênfase | regra transversal | cliques do usuário, baixos; nenhum |
| SFX em transições/motion | skill do cliente | whoosh/pop só em mudança visual real |
| Limpeza de fala | fala-limpa | cortar hesitações e outra voz (padrão) |

## D. Entrega

| Decisão | Fonte habitual | Opções típicas |
|---|---|---|
| Nome dos arquivos | regra transversal | `NN - HEADLINE.mp4` + `CAPA - NN - HEADLINE.png` |
| Onde entregar | pedido | pasta local; Drive (link); ClickUp |
| Prazo / urgência | pedido | hoje; sem pressa |
| Legenda e texto do post | pedido | só vídeo; vídeo + legenda do post + hashtags |
| Collab / marcações | pedido | collab com perfil Y; marcar Z |
| Aprovação | este skill | mapa de cortes + piloto (padrão); direto ao lote |
